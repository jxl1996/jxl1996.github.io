# 环境配置

环境变量配置：

```
PATH: flutter的bin目录

PUB_HOSTED_URL:https://pub.flutter-io.cn
FLUTTER_STORAGE_BASE_URL:https://storage.flutter-io.cn
```

检查环境：

```
flutter --version
dart --version
flutter doctor -v
```

创建flutter_web项目：

```
flutter create --platforms web 项目名称
```

trae编辑器需要安装的插件：

+ Flutter
+ Awesome Flutter Snippets
