# PDF.js 阅读器运行时

此目录基于 Mozilla PDF.js `v6.3.289` 官方预构建发行包，用于站内 `PdfViewer` 组件。

上游来源：https://github.com/mozilla/pdf.js/releases/tag/v6.3.289

为控制发布体积，本仓库仅保留阅读器运行所需的构建文件、字体、CMap、WASM、图像以及简体中文和英文语言包，移除了示例 PDF、调试器和源码映射。

本站改动：

- 默认使用简体中文和适应页宽。
- 不读写 PDF.js 阅读历史，每次从文档初始位置打开。
- 禁用并隐藏打印入口。
- 禁用拖放及快捷键打开本地文件，并隐藏对应入口。
- 隐藏标注相关入口。
- 通过 `site-overrides.css` 承载站点定制，尽量减少对上游文件的修改。
