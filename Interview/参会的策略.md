## 参会的策略

公司给了老杜去“北京网络安全大会”学习的机会，主办方在国家会议中心一天中安排了几十个分会场在同时举行各种主题会议，会场人声鼎沸。

老杜的策略是：参加尽可能多的会议，于是老杜拿到了当天所有会议的日程表，表上是每个会议的开始结束时间段[starttime,endtime]，假设时间都为整数，请问老杜这天最多能参加几个会议？

补充说明：

```
1、一天中所有的会议日程用一个二维数组表示，如：[[8,9],[8,10],[9,12],[10,16],[15,16]]，数组中的时间用整数（24小时制）表示。
2、老杜没有分身，参会的时间段不能重合。
```

示例1

输入例子：

```
[[8,9],[9,10],[9,12],[14,16],[15,16]]
```

输出例子：

```
3
```

示例2

输入例子：

```
[[9,11],[10,12],[14,16],[14,15]]
```

输出例子：

```
2
```



### 题目解析

在会议时间重叠的情况下，为了参加尽可能多的会议，核心策略不是看谁开始得早，也不是看谁持续时间短，而是**看谁结束得最早**。

**核心解题策略：最早结束时间优先**

老杜应该始终选择在当前可选会议中**结束时间（endtime）最早**的一个。

**逻辑证明：** 当你选择了一个结束时间最早的会议，你就为后续的会议留出了**最大限度的时间空间**。即便有其他会议更短，但如果它结束得晚，就会挤占后面更多会议的可能性。

------

**算法实现步骤**

1. **排序**：将所有会议按照**结束时间（endtime）**从小到大进行升序排列。
2. **初始化**：选择第一个会议（结束最早的），计数为 1，并记录其结束时间为 `last_end_time`。
3. **遍历与比较**：从第二个会议开始遍历：
   - 如果当前会议的 `starttime` **大于或等于** `last_end_time`（说明两个会议不冲突）；
   - 则参加这个会议，计数加 1，并更新 `last_end_time` 为当前会议的结束时间。
4. **输出结果**：遍历结束后的计数即为最大会议数。



### 代码实现:

```go
func AttendMeetings(times [][]int) int {
	if len(times) == 0 {
		return 0
	}

	// 按结束时间排序
	sort.Slice(times, func(i, j int) bool {
		return times[i][1] < times[j][1]
	})

	count := 1
	lastEndTime := times[0][1]
	for i := 1; i < len(times); i++ {
		if lastEndTime <= times[i][0] {
			count++
			lastEndTime = times[i][1]
		}
	}
	return count
}
```
