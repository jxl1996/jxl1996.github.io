## grep

面试题：在服务器中，某些文件中有一些特定的字符串，如“abcdefg”，如何找出在哪些文件中存在这个字符串

几种常用的 `grep` 命令用法：

1. 最基础、最常用的用法：在当前目录及其子目录中递归查找

```bash
grep -r "abcdefg" .
```

参数解释：

+ **`-r`** : 递归 (Recursive) 查找。它会查找当前目录以及所有子目录下的文件。

+ **`"abcdefg"`**: 你要查找的字符串。

+ **`.`**: 表示当前目录。你也可以把它替换成具体的路径，例如 `/var/log`。

2. 如果只想知道“哪些文件”包含字符串，而不关心具体内容，可以使用 `-l` (小写字母L) 参数：

```bash
grep -rl "abcdefg" .
```

3. **忽略大小写 (`-i`)**: 如果文件里有 "AbcDefg" 或 "ABCDEFG"，默认的 grep 是找不到的。

```bash
grep -ri "abcdefg" .
```

4. **精确匹配整个单词 (`-w`)**: 如果你只想找独立的 "abcdefg"，而不想找 "abcdefg123" 或 "pre_abcdefg"。

```bash
grep -rw "abcdefg" .
```

5. **显示行号 (`-n`)**: 在显示具体内容时，顺便把行号也标出来，方便定位。

```bash
grep -rn "abcdefg" .
```
