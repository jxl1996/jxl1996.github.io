# ADR-0002：使用 PDF.js 展示显式导入的站内 PDF

## 状态

已接受

## 背景

知识库需要在文章内提供功能完整且行为一致的 PDF 阅读体验，同时允许 PDF 跟随所属主题存放，不强制集中到 `public` 目录。VitePress 不会自动把 Markdown 链接中的 PDF 纳入构建产物，自行实现文本层、搜索、缩略图和目录的维护成本也较高。

## 决策

- 通过全局 `PdfViewer` 组件封装 PDF.js 官方阅读器，保持 Markdown 调用接口稳定。
- PDF 可以存放在任意主题子目录，由文章使用 `?url` 显式导入，使 Vite 将其作为静态资源发布。
- 阅读器仅加载站内 PDF，不支持外部 URL。
- 保留翻页、缩放、适应宽度、旋转、全屏、下载、文本搜索、缩略图和文档目录，隐藏打印及标注入口。
- 桌面端默认连续浏览，移动端默认单页浏览；组件进入视口附近后再初始化。
- 不记录或恢复 PDF 阅读位置。
- 阅读器沿用现有访问门，不引入服务端鉴权，也不将其视为 PDF 内容保密机制。

## 影响

- 扫描版 PDF 没有文本层时不能搜索，本站不额外提供 OCR。
- 隐藏打印入口不等于阻止浏览器打印、下载、截图或直接访问已发布的 PDF 资源。
- 更换阅读器内核时应保持 `PdfViewer` 的文章调用接口兼容。
