# ADR-0001：使用前端密码门控制文档访问

## 状态

已接受

## 背景

本站使用 VitePress 构建，并部署到 GitHub Pages。项目需要降低普通访客直接浏览文档的概率，同时不引入服务端账户系统。

## 决策

- 在主题层增加独立 `/auth` 密码页，未授权时不渲染默认主题内容。
- 使用构建时注入的密码 SHA-256 哈希校验输入。
- 在浏览器 `localStorage` 保存 30 天授权记录和授权版本号。
- 通过递增 `VITE_DOCS_AUTH_VERSION` 使旧授权失效。
- 生产构建缺少 `VITE_DOCS_PASSWORD_HASH` 时直接失败。

## 限制

这是客户端访问门，不是内容保密机制。GitHub Pages 上已经发布的 HTML、搜索索引、图片和其他静态资源仍可能被技术用户直接请求或从仓库获取。如果需要保护内容本身，应迁移到支持服务端鉴权的部署方案。
