# 图片点击预览大图功能设计

## 1. 背景与目标

当前项目是一个以 Markdown 内容为主的 VitePress 笔记站点，主题层扩展较轻，主要通过 `.vitepress/theme/index.ts` 和 `.vitepress/theme/custom.css` 做全局定制。

本次目标是在**不修改现有 Markdown 内容写法**的前提下，为文档正文中的图片增加统一的点击预览能力，满足以下体验：

- 点击正文图片后弹出全屏预览层
- 预览层支持鼠标滚轮缩放
- 预览层提供放大、缩小、重置、关闭按钮
- 支持按 `Esc` 或点击遮罩空白处关闭
- 页面路由切换后，新页面中的正文图片仍然可用

## 2. 当前项目约束

结合现有代码结构，设计需要遵守以下约束：

- 主题入口目前仅在 `.vitepress/theme/index.ts` 扩展默认主题
- 全局样式集中在 `.vitepress/theme/custom.css`
- 项目偏向内容站点，适合使用零依赖或极轻量实现
- 不应影响导航、首页非正文区域、主题图标等非正文图片
- 不计划改动 Markdown 文件中的图片写法，也不要求作者额外添加标记

## 3. 方案结论

采用**零依赖的主题层灯箱方案**。

实现方式是在 VitePress 主题层增加一个全局客户端增强逻辑，只对 `.vp-doc` 正文区域内的图片生效。点击图片时，打开自定义全屏预览层，并在预览层内维护当前图片地址、缩放比例和开关状态。

选择该方案的原因：

- 与当前项目的轻量主题扩展方式一致
- 不引入第三方图片预览依赖，维护成本低
- 改动集中，后续容易继续补充拖拽、切换图片等能力

不选择第三方库方案的原因：

- 当前需求仅包含预览与缩放，体量较小
- 引入依赖会增加包体积和维护成本
- 对内容型站点而言收益不如自定义方案明显

## 4. 功能范围

### 4.1 本次实现范围

- 对全部正文图片启用点击预览
- 打开全屏遮罩层显示当前图片
- 支持鼠标滚轮缩放
- 支持按钮放大、缩小、重置、关闭
- 支持 `Esc` 关闭
- 支持点击遮罩空白处关闭
- 每次打开新图片时重置缩放比例
- 路由切换后自动恢复图片预览能力

### 4.2 明确不在本次范围内

- 上一张 / 下一张图库式浏览
- 图片拖拽平移
- 移动端双指缩放优化
- 为单独图片配置不同预览行为
- 为图片增加标题、下载、旋转等附加功能

## 5. 交互设计

### 5.1 打开预览

用户点击 `.vp-doc` 正文区域中的图片时，阻止默认跳转行为，打开全屏遮罩层，并在视口中央显示当前图片。

图片初始显示遵循以下规则：

- 以图片原始比例渲染
- 在不超出当前视口的前提下尽量放大显示
- 初始缩放状态统一视为 `1x`

### 5.2 缩放规则

支持两种缩放方式：

1. 鼠标滚轮连续缩放
2. 点击工具栏中的放大 / 缩小按钮

缩放规则如下：

- 最小缩放比例：`0.5x`
- 最大缩放比例：`4x`
- 点击“重置”按钮后恢复为 `1x`
- 打开新的图片时，缩放比例重置为 `1x`
- 只有在预览层打开时，滚轮缩放才生效

### 5.3 关闭规则

支持以下关闭方式：

- 点击遮罩空白区域关闭
- 点击关闭按钮关闭
- 按 `Esc` 键关闭

点击图片本身或工具栏按钮时，不应触发关闭。

## 6. 技术设计

### 6.1 文件改动

本次设计预计涉及以下文件：

- `.vitepress/theme/index.ts`
- `.vitepress/theme/custom.css`
- 可能新增一个主题层组件，例如 `.vitepress/theme/components/ImagePreview.vue`

### 6.2 推荐结构

推荐新增一个独立的预览组件，由主题入口统一挂载，而不是把所有逻辑直接堆在主题入口文件中。

建议职责拆分如下：

#### 主题入口

`/.vitepress/theme/index.ts`

职责：

- 扩展默认主题
- 在客户端挂载图片预览组件
- 保持现有主题入口职责清晰

#### 图片预览组件

`/.vitepress/theme/components/ImagePreview.vue`

职责：

- 监听正文区域图片点击事件
- 维护预览打开状态
- 维护当前图片地址
- 维护当前缩放比例
- 处理滚轮缩放、按钮缩放、关闭行为
- 在路由切换后重新识别正文图片

#### 样式文件

`/.vitepress/theme/custom.css`

职责：

- 定义图片可点击状态的样式（如光标）
- 定义预览遮罩层、图片容器、工具栏按钮样式
- 控制层级、对齐、过渡与暗色主题下的视觉表现

### 6.3 事件策略

正文图片识别建议采用**作用域限制 + 统一事件处理**的方式：

- 只在 `.vp-doc` 区域内查找或代理 `img`
- 忽略导航栏、首页 Hero、主题装饰图片
- 路由切换后重新建立正文图片交互

这样可以把影响面限制在文档正文，不污染整个站点。

### 6.4 路由切换处理

由于 VitePress 页面是客户端路由切换，正文 DOM 会变化，因此不能只在首次加载时绑定一次。

设计要求在以下时机确保功能重新生效：

- 页面首次挂载后
- 路由切换完成后

实现时可以监听路由变化或在组件更新后重新扫描正文区域。

## 7. 样式设计

预览层样式目标如下：

- 使用全屏固定定位遮罩层
- 背景采用半透明深色蒙层
- 图片在屏幕中心显示
- 工具栏固定在预览层上方或右上角
- 按钮样式与当前暗色主题保持协调
- 正文可预览图片显示为可点击态，例如 `cursor: zoom-in`

为避免样式污染，预览层相关类名应使用明确前缀，例如 `image-preview-*`。

## 8. 边界与兼容性

### 8.1 链接包裹图片

若正文中存在 `a > img` 结构，点击图片时优先进入图片预览，而不是直接跳转链接。这与用户对“点击图片看大图”的预期更一致。

### 8.2 超大图片

即使原图尺寸很大，初始展示也必须限制在视口范围内，避免图片溢出屏幕导致首屏不可见。

### 8.3 非正文图片

首页装饰图、导航图标、主题内置图片等非 `.vp-doc` 区域图片不启用此功能。

### 8.4 移动端

本次移动端仅保证以下基础能力：

- 可以点击打开图片预览
- 可以点击关闭按钮或遮罩关闭

不承诺本次实现双指缩放、拖拽平移等移动端高级交互。

## 9. 验证方案

实现完成后需要通过本地站点实际验证，而不是只看代码。

验证项如下：

1. 任意 Markdown 正文图片可点击打开预览
2. 预览层显示位置正确，图片可见
3. 鼠标滚轮缩放正常
4. 放大、缩小、重置按钮工作正常
5. 点击遮罩空白处可以关闭
6. 按 `Esc` 可以关闭
7. 点击关闭按钮可以关闭
8. 从一个页面切换到另一个页面后，图片预览仍然生效
9. 非正文区域图片不会误触发预览

## 10. 风险与控制

### 风险 1：路由切换后事件失效

控制方式：在主题层显式处理页面切换后的重新绑定或重新识别。

### 风险 2：选择器范围过大，误伤非正文图片

控制方式：严格限制作用域为 `.vp-doc`，不要对全站 `img` 生效。

### 风险 3：滚轮缩放体验过于灵敏或比例失控

控制方式：限制缩放上下界，并提供重置按钮恢复到稳定状态。

## 11. 交付结果

本次设计完成后，实施阶段应交付：

- 一个挂载在 VitePress 主题层的图片预览能力
- 一套支持滚轮和按钮缩放的灯箱预览交互
- 限定在正文区域内生效的样式与事件处理
- 经本地运行验证通过的最终实现
