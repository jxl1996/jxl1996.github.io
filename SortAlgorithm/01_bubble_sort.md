# 冒泡排序

## 一、冒泡排序的核心思想

冒泡排序就像“水里的气泡往上冒”：

较大的数会通过一次次相邻交换，慢慢移动到数组右边。

它的基本流程是：

1. 从左到右比较相邻两个元素。
2. 如果前面的元素比后面的元素大，就交换。
3. 一轮比较结束后，当前未排序部分的最大值一定会到最右边。
4. 下一轮继续比较，但已经排好的最右边元素不用再比较。
5. 重复这个过程，直到整个数组有序。

<br/>

一句话理解：

```
冒泡排序就是不断比较相邻元素，把大的数一步一步交换到右边。
```



## 二、内层循环次数

假设数组长度是 `n`。

第 1 轮结束后，最大值已经在最后一位。

第 2 轮结束后，倒数第二位也已经排好。

第 3 轮结束后，倒数第三位也已经排好。

所以第 `i` 轮时，右边已经有 `i` 个元素排好了，不需要再比较。

因此内层循环范围是：

```
j < n-1-i
```

比如数组长度是 5：

| 轮数    | i    | 需要比较的次数 | 原因                    |
| ------- | ---- | -------------- | ----------------------- |
| 第 1 轮 | 0    | 4 次           | 5 个元素，需要比较 4 对 |
| 第 2 轮 | 1    | 3 次           | 最后 1 个已排好         |
| 第 3 轮 | 2    | 2 次           | 最后 2 个已排好         |
| 第 4 轮 | 3    | 1 次           | 最后 3 个已排好         |



## 三、代码实现-基础版

```go
package main

import "fmt"

func bubbleSort(arr []int) {
	n := len(arr)

	for i := 0; i < n-1; i++ {
		for j := 0; j < n-1-i; j++ {
			if arr[j] > arr[j+1] {
				arr[j], arr[j+1] = arr[j+1], arr[j]
			}
		}
	}
}

func main() {
	arr := []int{5, 3, 8, 4, 2}

	fmt.Println("排序前：", arr)

	bubbleSort(arr)

	fmt.Println("排序后：", arr)
}
```



## 四、Go 代码实现-优化版

基础版的问题是：即使数组已经有序，它还会继续比较。

比如：

```
[1, 2, 3, 4, 5]
```

它本来就是有序的，但基础版还是会继续循环。

所以可以加一个 `swapped` 标记：

如果某一轮没有发生任何交换，说明数组已经有序，可以提前结束。

```go
package main

import "fmt"

func bubbleSort(arr []int) {
	n := len(arr)

	for i := 0; i < n-1; i++ {
		swapped := false

		for j := 0; j < n-1-i; j++ {
			if arr[j] > arr[j+1] {
				arr[j], arr[j+1] = arr[j+1], arr[j]
				swapped = true
			}
		}

		if !swapped {
			break
		}
	}
}

func main() {
	arr := []int{5, 3, 8, 4, 2}

	fmt.Println("排序前：", arr)

	bubbleSort(arr)

	fmt.Println("排序后：", arr)
}
```



## 五、复杂度

| 情况       | 时间复杂度 |
| ---------- | ---------- |
| 最好情况   | `O(n)`     |
| 平均情况   | `O(n²)`    |
| 最坏情况   | `O(n²)`    |
| 空间复杂度 | `O(1)`     |

最好情况是数组本身已经有序，并且代码中使用了 `swapped` 提前结束优化。

冒泡排序是**稳定排序**。因为只有当前一个元素大于后一个元素时才交换：

```
if arr[j] > arr[j+1]
```

如果两个元素相等，不会交换，所以相同元素的相对顺序不会被破坏。
