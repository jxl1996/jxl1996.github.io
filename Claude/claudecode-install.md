# Claude Code 安装

## 1. Claude Code 安装（CLI ）

> [!NOTE]
>
> **前置要求**
>
> - **Node.js：** 必须安装 Node.js 18.0.0 或更高版本
> - **Git：** 必须安装 Git。

全局安装：

```bash
npm install -g @anthropic-ai/claude-code
```

验证安装：

```bash
claude --version
```
