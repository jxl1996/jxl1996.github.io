# 形状绘制工具

## 一、矩形

+ 快捷键：R
+ 正方形绘制：按住Shift 再鼠标拖动
+ 缩放的时候等比例：按住Shift 再鼠标拖动
+ 矩形内部四个角的小圆：
  + 拖动可设置圆角 (Radius)
  + 按住Shift 再鼠标拖动：圆角每次增加或减少10
  + 按照Alt再鼠标拖动：只单独设置某一个角的圆角

+ 旋转：
  + 操作方法：鼠标移动到四个角，光标变成弧线的双向箭头，这个时候鼠标拖动旋转即可
  + 按住Shift，然后再旋转：每次旋转15度

---

## 二、圆形

+ 快捷键：O
+ 正圆绘制：按住Shift 再鼠标拖动
+ 缩放的时候等比例：按住Shift 再鼠标拖动
+ 旋转：与矩形同理
+ 圆形内部的3个小圆：
  + Sweep： 控制饼状图大小
  + Start： 控制饼状图开始的角度
  + Ratio：控制饼状图内部小圆占比多少

---

## 三、多边形

+ 快捷键：无
+ 等边三角形绘制：按住Shift 再鼠标拖动
+ 缩放的时候等比例：与上同理
+ 旋转：与上同理
+ 多边形内部的2个小圆：
  + Radius：控制圆角半径
  + Count：控制多边形的边数

---

## 四、星形

+ 快捷键：无
+ 正五角星绘制：按住Shift 再鼠标拖动
+ 缩放的时候等比例：与上同理
+ 旋转：与上同理
+ 内部的3个小圆：
  + Radius：控制星星尖端的圆角大小
  + Ratio: 控制夹角
  + Count：控制星星是几角：例如五角星、六角星
