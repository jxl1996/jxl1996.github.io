# 线性图标绘制

## 一、绘制Keyline

第1步：创建一个24*24的画框

![image-20260820121637336](./assets/image-20260820121637336.png)

第2步：绘制对角线

![image-20260820122220929](./assets/image-20260820122220929.png)

+ P：钢笔工具，绘制一条对角线
+ V：取消钢笔工具
+ 选中刚才画的对角线：Ctrl+D 复制一条对角线
+ Shift+H：水平翻转这条对角线

第3步：绘制”米“字线

![image-20260820125522008](./assets/image-20260820125522008.png)

先画一条横线或竖线，然后复制，再旋转90度。

> [!NOTE]
>
> 水平线或垂直线，需要旋转90度，而不是水平或垂直翻转，因为水平或垂直翻转后依然是原样的一条线

第4步： 绘制一个圆

![image-20260820130802889](./assets/image-20260820130802889.png)



+ 先绘制一个圆
+ 选中任意一条线，复制属性
+ 选中圆，粘贴属性

第5步：创建两个矩形

![image-20260820131441584](./assets/image-20260820131441584.png)

第6步：绘制一个正方形

![image-20260820131659146](./assets/image-20260820131659146.png)

第7步：中间再绘制1个小圆

![image-20260820131854250](./assets/image-20260820131854250.png)

+ 选中上面创建的大圆，Ctrl + D 复制
+ 选中复制这个圆，按住Shift + Alt，然后拖动鼠标进行缩放

第8步：给三个矩形添加圆角半径

![image-20260820132619866](./assets/image-20260820132619866.png)



+ 选中三个矩形
+ 设置圆角半径：1

第9步：合并所有的辅助线图层

![image-20260820132815113](./assets/image-20260820132815113.png)



+ 选中所有的辅助线图层 -> 进行Union
+ 设置透明度：比如20%



至此，就绘制完成了一个Keyline

## 二、绘制小房子图标

第1步：如果担心后续编辑误操作到辅助线，可以先将辅助线图层锁定

第2步：绘制一个正方形，让该正方形卡在辅助线最中心的正方形上

![image-20260821083429010](./assets/image-20260821083429010.png)

+ 绘制一个正方形，让该正方形卡在辅助线最中心的正方形上
+ 取消正方形填充色
+ 添加正方形描边：Center，宽度为2

第3步：制作房顶

![image-20260821083959620](./assets/image-20260821083959620.png)



+ 进入编辑模式
+ 在矩形顶部横线的中心添加一个锚点
+ 按住Shift选择顶部左右两个锚点
+ 鼠标往下拖，脱出一个房顶的形状

第4步：删除描边，添加一个填充（方便后面做布尔运算进行查看）

![image-20260821084345396](./assets/image-20260821084345396.png)

第5步：绘制底部小门

![image-20260821085853319](./assets/image-20260821085853319.png)

第6步：进行布尔运算：减去

![image-20260821090025979](./assets/image-20260821090025979.png)

+ 选中小房子和小门：布尔运算->减去
+ 调整校门的圆角：4

第7步：对减去后图层，再进行描边：Center，宽度2

![image-20260821090307017](./assets/image-20260821090307017.png)

第8步：给小房子添加一个圆角：1

![image-20260821090443047](./assets/image-20260821090443047.png)
