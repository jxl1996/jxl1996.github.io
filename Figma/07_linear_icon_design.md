# 线性图标绘制

## 一、绘制Keyline

第1步：创建一个24*24的画框

![image-20260820121637336](./assets/image-20260820121637336.png)

第2步：绘制对角线

![image-20260820122220929](./assets/image-20260820122220929.png)

+ P：钢笔工具，绘制一条对角线
+ V：取消钢笔工具
+ 选中刚才画的对角线：Ctrl+D 复制一条对角线
+ Shift+H：水平翻转这条对角线

第3步：绘制”米“字线

![image-20260820125522008](./assets/image-20260820125522008.png)

先画一条横线或竖线，然后复制，再旋转90度。

> [!NOTE]
>
> 水平线或垂直线，需要旋转90度，而不是水平或垂直翻转，因为水平或垂直翻转后依然是原样的一条线

第4步： 绘制一个圆

![image-20260820130802889](./assets/image-20260820130802889.png)



+ 先绘制一个圆
+ 选中任意一条线，复制属性
+ 选中圆，粘贴属性

第5步：创建两个矩形

![image-20260820131441584](./assets/image-20260820131441584.png)

第6步：绘制一个正方形

![image-20260820131659146](./assets/image-20260820131659146.png)

第7步：中间再绘制1个小圆

![image-20260820131854250](./assets/image-20260820131854250.png)

+ 选中上面创建的大圆，Ctrl + D 复制
+ 选中复制这个圆，按住Shift + Alt，然后拖动鼠标进行缩放

第8步：给三个矩形添加圆角半径

![image-20260820132619866](./assets/image-20260820132619866.png)



+ 选中三个矩形
+ 设置圆角半径：1

第9步：合并所有的辅助线图层

![image-20260820132815113](./assets/image-20260820132815113.png)



+ 选中所有的辅助线图层 -> 进行Union
+ 设置透明度：比如20%



至此，就绘制完成了一个Keyline
